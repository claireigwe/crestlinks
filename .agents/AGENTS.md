# CrestLinks AI Agent Guide

## Purpose

This file is the entry point for every AI agent working on the CrestLinks project.

Before completing any task, follow the workflow defined here and use the referenced documentation rather than making assumptions.

---

# Workflow

Every task must follow this sequence:

1. Understand the business.
2. Understand the requested task.
3. Plan the solution.
4. Build the solution.
5. Review the solution.
6. Refine where necessary.
7. Complete the task.

Never skip planning or review.

---

# Skills

Use the following skills as appropriate.

Always begin with:

- Company Understanding

Then use one or more of:

- Create Page
- Create Component
- Design Review
- Content Review
- Critical Review

Critical Review should always be the final step.

# Design Principles

The website should feel:

- Premium
- Modern
- Editorial
- Bright
- Spacious
- Professional

Interactions should remain subtle and purposeful.

Always use the project's design tokens.

---

# Development Principles

Prefer:

- Reusable components.
- Server Components.
- Semantic HTML.
- CSS Modules.
- Accessibility.
- Performance.

Avoid unnecessary abstraction.

---

# Content Principles

Write for international B2B buyers.

Build trust before asking for action.

Never invent business information.

---

# Before Completing Any Task

Confirm that:

- The business objective has been met.
- The solution follows the project documentation.
- The appropriate skills were executed.
- Accessibility has been maintained.
- The implementation is responsive.
- Existing components were reused where appropriate.
- The Critical Review skill has been completed.

Only then should the task be considered complete.

# Design Review

## Objective

Evaluate completed interface designs to ensure they align with the CrestLinks brand, support the intended user journey, and deliver a premium user experience.

This skill focuses exclusively on design quality.

It should assess visual communication, usability, interaction design, layout composition, hierarchy, and overall user experience.

It should not review implementation details, code quality, or business logic.

---

# When to Use

Use this skill after:

- Designing a new page.
- Updating an existing page.
- Creating a new layout.
- Introducing new interactions.
- Completing major UI changes.
- Before requesting implementation.

Do not use this skill to review code.

# Preconditions

Before beginning the review, confirm:

- The page or interface has been designed.
- The intended audience is known.
- The business objective is understood.
- The content has already been approved.

Design should never compensate for poor content.

---

# Workflow

## Step 1 — Review the First Impression

Evaluate the interface within the first few seconds.

Ask:

- Does this immediately feel premium?
- Does it communicate professionalism?
- Would an international buyer trust this company?

If the first impression is weak, identify why.

---

## Step 2 — Review the Visual Hierarchy

Confirm users can immediately identify:

- Primary message
- Supporting information
- Primary action

Nothing should compete unnecessarily for attention.

Hierarchy should be obvious without relying on colour alone.

---

## Step 3 — Review Layout & Composition

Evaluate:

- Section order.
- Grid consistency.
- Alignment.
- Balance.
- Whitespace.
- Content density.

Every section should have room to breathe.

Avoid repetitive layouts.

Ensure the page creates visual rhythm from top to bottom.

---

## Step 4 — Review User Journey

Ask:

- Does every section naturally lead to the next?
- Does the page tell a coherent story?
- Is information progressively disclosed?
- Is the primary CTA reached naturally?

Visitors should never feel lost.

---

## Step 5 — Review Components

Confirm that components:

- Feel consistent.
- Support the content.
- Do not dominate the page.
- Follow established design patterns.

Avoid decorative components that provide no value.

---

## Step 6 — Review Imagery

Evaluate whether imagery:

- Feels authentic.
- Supports the message.
- Builds trust.
- Maintains visual consistency.
- Feels bright and premium.

Avoid generic or repetitive imagery.

---

## Step 7 — Review Interaction Design

Review:

- Hover states.
- Scroll behaviour.
- Motion.
- Micro-interactions.
- Feedback.

Ask:

Does every interaction have a purpose?

Remove interactions that exist only for decoration.

Motion should improve understanding, not distract from it.

---

## Step 8 — Review Accessibility

Confirm the design supports:

- Clear contrast.
- Readable typography.
- Visible focus states.
- Logical navigation.
- Responsive layouts.

Accessibility should feel naturally integrated.

---

## Step 9 — Challenge the Design

Before approving, ask:

- Does this feel bespoke or templated?
- Does this reflect the CrestLinks brand?
- Is there unnecessary visual noise?
- Is there enough whitespace?
- Can anything be simplified?
- Would I confidently present this to an international client?

Challenge assumptions before approving the design.

---

# Validation Checklist

Confirm:

✓ The design feels premium.

✓ The first impression builds trust.

✓ The hierarchy is clear.

✓ Layouts create visual rhythm.

✓ Components are consistent.

✓ Imagery supports the story.

✓ Interactions feel intentional.

✓ Accessibility has been considered.

✓ The page supports the buyer journey.

✓ The interface reflects the CrestLinks brand.

---

# Common Mistakes

Avoid:

- Generic landing page layouts.
- Repetitive section structures.
- Decorative animations.
- Visual clutter.
- Weak hierarchy.
- Poor spacing.
- Inconsistent component usage.
- Over-designed interfaces.
- Prioritising aesthetics over usability.

---

# Completion Criteria

A design is complete when:

- It communicates the intended message immediately.
- It reinforces trust.
- It supports the buyer journey.
- It feels visually cohesive.
- It aligns with the CrestLinks brand.
- It follows the design direction.
- It is accessible.
- It is responsive.
- It feels production-ready.

The final interface should feel like the digital presence of a premium international export company rather than a generic marketing website.

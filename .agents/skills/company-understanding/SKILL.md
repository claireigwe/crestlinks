# Company Understanding

## Objective

Develop a complete understanding of CrestLinks before making any design, development, or content decisions.

This skill ensures every implementation aligns with the company's business goals, brand positioning, target audience, and website objectives.

No work should begin until sufficient project context has been gathered.

---

# When to Use

Use this skill before:

- Designing pages
- Creating components
- Writing content
- Planning layouts
- Making UX decisions
- Implementing features
- Reviewing work

This skill should be the first skill executed for any new task.

---

# Required Context

Read and understand the following documents before proceeding:

- vision.md
- brand.md
- audience.md
- company.md
- products.md
- sitemap.md
- content.md
- seo.md
- design-direction.md

Do not make assumptions when information already exists within these documents.

---

# Preconditions

Before continuing, confirm that:

- Project documentation exists.
- Business objectives are understood.
- Target audience is understood.
- Brand positioning is understood.
- Design direction has been reviewed.
- Requested task is clearly defined.

If any of these conditions are not met, stop and resolve the missing context before continuing.

---

# Workflow

## Step 1

Understand the business.

Identify:

- What CrestLinks does.
- Who CrestLinks serves.
- What problem the company solves.
- What makes CrestLinks different.

---

## Step 2

Understand the audience.

Identify:

- Primary users.
- Business goals.
- Buyer concerns.
- Decision-making process.

Every future decision should support these users.

---

## Step 3

Understand the brand.

Review:

- Brand personality.
- Tone of voice.
- Messaging pillars.
- Desired perception.

Every output should reinforce the brand.

---

## Step 4

Understand the website.

Identify:

- Primary purpose.
- User journey.
- Page hierarchy.
- Primary calls-to-action.

The website exists to generate qualified enquiries while building trust.

---

## Step 5

Understand the requested task.

Determine:

- Business objective.
- User objective.
- Expected outcome.

Avoid solving problems that were not requested.

---

## Step 6

Create an implementation plan.

Before producing any output, mentally determine:

- Existing resources that can be reused.
- Components likely to be required.
- Relevant documentation.
- Potential constraints.

Always prefer reuse over creating new solutions.

---

# Validation Checklist

Before continuing, confirm:

✓ I understand the company's goals.

✓ I understand the target audience.

✓ I understand the brand.

✓ I understand the website structure.

✓ I know where the relevant documentation is located.

✓ I understand the requested task.

✓ I can complete the task without making assumptions.

---

# Common Mistakes

Avoid:

- Skipping documentation.
- Making assumptions.
- Inventing business information.
- Solving problems outside the requested scope.
- Ignoring existing project standards.
- Recreating information already documented elsewhere.

---

# Completion Criteria

This skill is complete when:

- The business is understood.
- The audience is understood.
- The brand is understood.
- The website objectives are understood.
- The requested task is clearly defined.
- All required context has been reviewed.

Only then should implementation begin.

# SEO

## Overview

This document defines the search engine optimisation strategy for the CrestLinks website.

The objective is to improve discoverability while maintaining a premium user experience.

SEO should never compromise readability, credibility, or the company's professional positioning.

Content should always be written for people first and search engines second.

---

# SEO Objectives

The website should:

- Increase visibility for relevant agricultural export searches.
- Attract qualified international buyers.
- Strengthen CrestLinks' online credibility.
- Support long-term organic growth.
- Encourage qualified enquiries rather than maximise website traffic.

Traffic without relevant buyers is not considered success.

---

# Primary Search Intent

The website targets businesses looking to source Nigerian agricultural commodities.

Typical visitor intent includes:

- Finding Nigerian agricultural exporters.
- Looking for trusted export partners.
- Sourcing agricultural commodities.
- Requesting export quotations.
- Learning about export capabilities.

The website should answer these needs naturally.

---

# Target Audience

SEO should prioritise searches made by:

- Importers
- Procurement Managers
- Commodity Traders
- Wholesale Buyers
- Food Manufacturers
- International Distributors

Content should not target retail consumers.

---

# Keyword Strategy

## Primary Keywords

- Nigerian Agricultural Exporter
- Agricultural Commodities Export Nigeria
- Nigerian Export Company
- Agricultural Export Company
- Agricultural Commodity Supplier
- Agricultural Export Partner
- Export Agricultural Products from Nigeria

---

## Commodity Keywords

Each commodity should target its own search intent.

Examples include:

- Nigerian Cashew Exporter
- Nigerian Sesame Seed Exporter
- Nigerian Cocoa Exporter
- Nigerian Ginger Exporter
- Nigerian Hibiscus Exporter
- Nigerian Soybean Exporter
- Nigerian Shea Nut Exporter

Each product page should naturally include relevant terminology without keyword stuffing.

---

# Page Metadata

Every page should contain:

- Unique Page Title
- Meta Description
- Open Graph Title
- Open Graph Description
- Social Sharing Image
- Canonical URL

No page should duplicate another page's metadata.

---

# URL Structure

URLs should remain simple and descriptive.

Examples:

/

/about

/products

/export-services

/contact

Future product pages:

/products/cashew-nuts

/products/sesame-seeds

/products/cocoa-beans

URLs should always use lowercase letters and hyphens.

---

# Heading Structure

Each page should contain:

One H1

Logical H2 hierarchy

Supporting H3 sections where appropriate

Headings should improve readability rather than simply include keywords.

---

# Internal Linking

Every page should support the buyer journey.

Recommended links include:

Home → Products

Home → About

Products → Contact

Products → Export Services

Export Services → Contact

About → Contact

Important pages should never become isolated.

---

# Image Optimisation

Every image should include:

- Descriptive filename
- Appropriate alt text
- Optimised dimensions
- Modern image formats
- Responsive sizing

Alt text should describe the image rather than repeat keywords.

---

# Structured Data

Where appropriate, implement structured data for:

- Organization
- Website
- Breadcrumbs
- Contact Information

Additional structured data may be introduced as the website grows.

---

# Technical SEO

The website should:

- Load quickly.
- Be mobile friendly.
- Use semantic HTML.
- Be accessible.
- Generate sitemap.xml.
- Generate robots.txt.
- Use canonical URLs.
- Avoid duplicate content.
- Optimise Core Web Vitals.

Performance should remain a priority.

---

# Open Graph

Every page should support high-quality social sharing.

Include:

- Title
- Description
- Featured Image
- Canonical URL

The social preview should reflect the CrestLinks brand.

---

# Content Strategy

Content should:

- Demonstrate expertise.
- Build trust.
- Answer buyer questions.
- Support business conversations.
- Remain evergreen where possible.

Avoid publishing content purely to target keywords.

---

# Local SEO

Although CrestLinks serves international buyers, the website should clearly establish its Nigerian presence.

Include:

- Company location.
- Contact information.
- Business details.
- Export capability.

This strengthens credibility for international visitors.

---

# Future SEO Opportunities

Potential future initiatives include:

- Individual product pages.
- Industry pages.
- Market-specific landing pages.
- Quality assurance pages.
- Sustainability page.
- Certifications page.
- Export guides.
- Frequently Asked Questions.

These are outside the scope of Version 1.

---

# SEO Success Metrics

The SEO strategy is successful when it:

- Attracts qualified international buyers.
- Improves search visibility for relevant export queries.
- Generates high-quality enquiries.
- Maintains strong technical performance.
- Supports CrestLinks' premium brand positioning.

Success should be measured by business enquiries rather than traffic alone.

---

# SEO Principles

Every SEO decision should follow these principles.

## Human First

Write for buyers before search engines.

---

## Quality Over Quantity

Publish fewer, better pages rather than many low-value pages.

---

## Relevance Over Volume

Target visitors who are likely to become customers.

---

## Trust Over Rankings

Never compromise the CrestLinks brand to achieve higher search rankings.

---

## Long-Term Value

Optimise for sustainable growth rather than short-term SEO tactics.
